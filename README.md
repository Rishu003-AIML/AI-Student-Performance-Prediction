## 🧠 ABOUT THE PROJECT

**AI Student Performance Predictor** is a Machine Learning-based application
designed to predict a student's expected final marks using important academic
factors.

Instead of looking only at past marks, the system considers multiple factors
together to generate an intelligent prediction.

### 📌 The model considers:

- 📅 Attendance
- ⏱️ Daily Study Hours
- 📝 Previous Examination Marks
- 📚 Assignment Marks
- 📊 Internal Assessment Marks

The final prediction is generated using a trained **Random Forest Regression**
model.

---

## ✨ WHY THIS PROJECT?

Students often want to know:

> **"Based on my current performance, what could my final marks look like?"**

Learning.

🎯 **Input academic data → 🤖 ML model → 📈 Predicted final marks**
